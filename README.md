# Космос рядом — интерактивная модель

Одностраничное учебное веб-приложение для демонстрации взаимного движения Солнца, Земли и Луны ребёнку 8–12 лет.

## Запуск

Файл `index.html` можно открыть напрямую в современном браузере. Для корректного поведения ES-модулей и локального предпросмотра рекомендуется:

```powershell
py -m http.server 4173
```

После этого открыть `http://localhost:4173` в браузере.

## Возможности

- Three.js, OrbitControls и lil-gui через CDN;
- вид из космоса и вид с поверхности в Краснодаре;
- полевой горизонт с движением светил по небу с востока на запад, вращением направления взгляда мышью и маркером Краснодара на глобусе;
- модельное время МСК, ручной выбор даты/времени, пауза, воспроизведение и ускорение;
- приближённые вычисления экваториальных и горизонтальных координат Солнца и Луны;
- календарный циферблат вокруг орбиты Земли с месяцами, сезонами северного полушария и отметкой Нового года;
- фазы Луны, высоты и азимуты светил, учебные сценарии затмений и сезонов;
- переключаемые орбиты, плоскости, оси, линии затмений, тени, горизонт и компас.

## Ограничения модели

Это наглядная учебная модель, а не астрономический планетарий: размеры увеличены для видимости, а расчёт положения Луны и затмений упрощён. Для production-публикации без сетевого доступа CDN-ресурсы нужно заменить локальными копиями Three.js.
